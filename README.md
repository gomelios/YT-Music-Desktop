

YouTube Music Desktop (PyQt6)

YouTube Music Desktop is a lightweight desktop wrapper built with PyQt6 and Qt WebEngine that provides a standalone YouTube Music experience without requiring a traditional web browser.

This application embeds a Chromium-based web engine to load the official YouTube Music web interface while offering native desktop integration such as system tray support and persistent login sessions.

Features:

-Embedded YouTube Music web interface

-System tray integration

-Minimize to tray instead of closing

-Built with Python and PyQt6

Technologies Used

-Python 3

-PyQt6

-Qt WebEngine

-PyInstaller (for executable builds)

This project aims to provide a clean and simple desktop experience for YouTube Music users who prefer a dedicated application over keeping a browser tab open.
